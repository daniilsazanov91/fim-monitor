File Integrity Monitoring (FIM)

Анализ систем контроля целостности файлов в информационной безопасности

Что такое FIM

FIM (File Integrity Monitoring) — это технология контроля изменений файлов в системе. Она позволяет обнаруживать несанкционированные изменения, удаление или добавление файлов.

Где применяется FIM

  • SOC и DFIR-расследования
  • Стандарты PCI DSS, ISO 27001, ГОСТ
  • Защита серверов Windows/Linux
  • Контроль системных и конфигурационных файлов
  • Обнаружение вредоносной активности

Принцип работы

Система создаёт эталон (baseline) хэшей файлов с использованием алгоритма SHA-256. При повторной проверке вычисляются новые хэши и сравниваются с эталоном. 

Файл → SHA256 → Baseline
Файл изменён → Новый SHA256 ≠ Baseline → Инцидент

Какие события обнаруживает FIM

  • Изменение файла (modified)
  • Удаление файла (removed)
  • Добавление нового файла (added)

Примеры реальных систем FIM

  • Wazuh / OSSEC
  • Tripwire
  • AIDE (Linux)
  • Windows File Integrity Monitoring

Демонстрация работы FIM (локально)

Для демонстрации был реализован собственный FIM-агент на Python, который вычисляет SHA256 файлов и формирует отчёт об изменениях. 

python app.py
http://127.0.0.1:5000

При изменении файлов система показывает: 

{
  "added": [],
  "removed": [],
  "modified": ["monitor_folder/test.txt"]
}

Вывод

FIM является важным инструментом обеспечения информационной безопасности, позволяющим своевременно выявлять компрометацию системы и изменения критически важных файлов.
